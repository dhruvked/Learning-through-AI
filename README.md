## 📚 How It Works

1. **Pick a Skill** — Choose a skill track to start learning
2. **Diagnostic Test** — Get assessed and placed at the right level
3. **Follow the Syllabus** — Learn from any resources you like
4. **Ask Questions** — AI tutor available throughout
5. **Take Tier Tests** — Prove mastery to level up
6. **Repeat** — Unlock the next tier and keep climbing

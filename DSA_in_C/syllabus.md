# 📜 DSA in C — Level 1 to 100 Syllabus

> A complete progression path from C memory fundamentals to master-level data structures and algorithms.

---

## 🟢 Tier 1: C Memory & Fundamental Data Structures (Levels 1 – 20)

- **Level 1–4**: C Syntax Refresher, Memory Layout (Stack vs Heap), Pointers & Dereferencing, Pointer Arithmetic.
- **Level 5–8**: Structs, Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`), Memory Leaks & Safety.
- **Level 9–12**: Static vs Dynamic Arrays, Reusable Dynamic Array (Vector) Implementation in C.
- **Level 13–16**: Singly Linked Lists, Doubly Linked Lists, Circular Linked Lists (Pointer manipulation).
- **Level 17–20**: Stacks & Queues (Array-based and Linked-List-based implementations).

---

## 🔵 Tier 2: Intermediate Trees & Searching (Levels 21 – 40)

- **Level 21–24**: Time & Space Complexity ($O(1), O(n), O(\log n)$), Asymptotic Analysis in C.
- **Level 25–28**: Recursion, Call Stack Analysis, Backtracking Fundamentals.
- **Level 29–32**: Binary Trees, Tree Traversals (In-order, Pre-order, Post-order, Level-order).
- **Level 33–36**: Binary Search Trees (BST) — Insertion, Deletion, Searching, Balance Concepts.
- **Level 37–40**: Heaps (Min-Heap, Max-Heap), Priority Queues, Hash Tables in C (Collision Handling via Chaining/Open Addressing).

---

## 🟡 Tier 3: Graphs & Dynamic Programming (Levels 41 – 60)

- **Level 41–44**: Graph Representations (Adjacency Matrix vs Adjacency List in C using dynamic memory).
- **Level 45–48**: Graph Traversals — Breadth-First Search (BFS), Depth-First Search (DFS).
- **Level 49–52**: Shortest Path Algorithms (Dijkstra’s Algorithm, Bellman-Ford) & Minimum Spanning Trees (Prim's / Kruskal's).
- **Level 53–56**: Bitwise Operations & Bitmasking in C (Flags, Bitwise Manipulation Techniques).
- **Level 57–60**: Dynamic Programming Fundamentals (Memoization vs Tabulation, 1D/2D DP Problems in C).

---

## 🔴 Tier 4: Advanced Interview Patterns & Memory Mastery (Levels 61 – 80)

- **Level 61–64**: Advanced Trees (AVL Trees, Red-Black Trees concepts, Trie / Prefix Tree in C).
- **Level 65–68**: Segment Trees, Binary Indexed Trees (Fenwick Tree), Disjoint Set Union (DSU / Union-Find).
- **Level 69–72**: Advanced DP (Knapsack variants, Longest Common Subsequence, Edit Distance in C).
- **Level 73–76**: String Matching Algorithms (KMP, Rabin-Karp) & Memory Sanitization (`valgrind`, `AddressSanitizer`).
- **Level 77–80**: Hard LeetCode / Technical Interview Problem Solving in C.

---

## 👑 Tier 5: Systems Mastery & Advanced C Optimizations (Levels 81 – 100)

- **Level 81–85**: Custom Memory Allocators (Fixed-size block allocators, Arena Allocators in C).
- **Level 86–90**: Cache Locality, Data-Oriented Design, Memory Alignment & Padding in C.
- **Level 91–95**: Lock-Free Data Structures (Atomic Operations, Multi-threaded SPSC/MPMC Queues in C).
- **Level 96–100**: Production-Grade C Library Design (Designing a high-performance DSA C Library).
